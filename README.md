# Vault — Savings Dashboard

1. Install Node.js 18 or newer from https://nodejs.org
2. In this folder run:  npm install
3. Start the app:       npm run dev     (opens http://127.0.0.1:5173)
4. Production build:    npm run build   (output in dist/, preview with npm run preview)

Data is stored in your browser's localStorage on this computer.
src/App.tsx is your uploaded file, unchanged.
